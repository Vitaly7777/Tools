# Сравнение CSV файлов

GUI-приложение для сравнения двух CSV файлов с поддержкой пользовательских схем, чанкового режима и агрегации дубликатов.

## Возможности

- **Сравнение по ключевым столбцам** — находит строки только в одном файле и различия в значениях
- **Пользовательские схемы** — задавайте типы столбцов, ключевые поля и точность float
- **Чанковый режим** — обработка больших файлов через SQLite без загрузки в память
- **Агрегация дубликатов** — sum, mean, min, max по неключевым столбцам
- **Ограничение отображения строк** — визуально видно только 3 строки на вкладку (скролл для остальных), лимит загрузки в UI настраивается (по умолчанию 10 000 строк)
- **Экспорт результатов** — Excel (.xlsx) или CSV (при >1M строк)
- **Автоматическое сохранение сессии** — восстанавливает последний запуск, включая настройки лимита строк

## Использование

1. **Загрузите файлы** — выберите два CSV/Excel файла
2. **Выберите схему** — из списка или создайте пользовательскую
3. **Настройте параметры** — разделитель, чанковый режим, агрегация, точность float, лимит строк
4. **Запустите сравнение** — нажмите кнопку или `Ctrl+R`
5. **Просмотрите результаты** — вкладки: только в df1, только в df2, различия
6. **Сохраните** — кнопка или `Ctrl+S`

### Лимит строк результатов

В панели настроек доступен параметр **"Лимит строк результатов"** (100–100 000, по умолчанию 10 000).

- Визуально на каждой вкладке отображается **не более 3 строк** (остальные доступны через прокрутку).
- Лимит определяет, сколько строк загружается в UI для предотвращения зависаний на больших данных.
- Кнопка **"Сброс (10K)"** возвращает значение по умолчанию.

### Схемы

Файл схем: `schemas.json`

Формат:
```json
{
  "schemas": {
    "Название схемы": {
      "schema": {
        "Столбец1": "string",
        "Столбец2": "float",
        "Столбец3": "int",
        "Столбец4": "bool"
      },
      "key_columns": ["Столбец1", "Столбец2"],
      "tolerance": 0.0
    }
  }
}
```

### Поддерживаемые типы

| Тип | pandas dtype | Примечание |
|---|---|---|
| `string` | `string` | — |
| `int` | `Int64` | nullable integer (поддерживает NaN) |
| `float` | `float64` | — |
| `bool` | `boolean` | nullable boolean (True/False/NA) |

### Режимы сравнения

#### In-Memory
- Загружает оба файла в память
- Подходит для файлов до ~500МБ
- Быстрее для небольших данных

#### Чанковый (SQLite)
- Читает по 50 000 строк
- Хранит ключи в памяти, полные строки — в SQLite
- Подходит для файлов >1GB
- Включается чекбоксом «Чанковый режим»

## Выходные данные

При сохранении создаётся папка с меткой времени:

```
tmp/Results/compare_csv/comparison_20261026_134201/
├── report_20261026_134201.xlsx   # Excel с вкладками
│   ├── Только в df1
│   ├── Только в df2
│   ├── Различия
│   └── Сводка
└── key_uniqueness_warnings.txt   # Предупреждения (если есть)
```

При >1M строк в любом наборе — сохраняется в CSV.
